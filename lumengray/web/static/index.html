LumenX calibration chip

A single full-build test print that measures how faithfully your LumenX reproduces dimensions and grayscale. Everything is a robust gel feature (no text/thin rulers — they don't print in hydrogel); labels live in the reference map. Export it, print it, measure under a microscope / calipers.

  • Scale rulers (X/Y) — true pixel pitch & anisotropy. Fixes "prints come out the wrong size."
  • Dimensional squares — is the scale error size-dependent?
  • Grayscale step wedge — which grays cure, and how (0→255).
  • Gray × feature matrix — how features grow (pillars) / shrink (holes) at each gray. The core map.
  • Resolution grating — smallest resolvable line pairs.
  • Outer frame & L-ruler — measurement datum, squareness/rotation, and orientation.

Parameters

Uses the resolution & voxel pitch from the studio's Printer card.
